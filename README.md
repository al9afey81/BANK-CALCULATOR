# حاسبة التمويل البنكي

صفحة عربية RTL مبنية باستخدام HTML وCSS وJavaScript فقط، متوافقة مع شاشات الهواتف وتدعم الإضافة لشاشة الآيفون الرئيسية عبر Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.

## الحساب

معادلة الأقساط الشهرية المتساوية على الرصيد المتناقص:

`A = P × r / (1 − (1 + r)^(-n))`

حيث `r = النسبة السنوية / 1200` و`n` عدد الأشهر. عند نسبة صفر: `A = P / n`. الأرباح = `A × n − P`. لا تقريب للنتائج الوسيطة؛ العرض إلى ثلاثة منازل عشرية. النتائج تقديرية ولا تشمل الرسوم أو التأمين. الأرقام شديدة الضخامة تخضع لحدود JavaScript العددية، وعدد الأشهر يقبل أي عدد صحيح موجب آمن دون قائمة مدد محددة.

النسبة الافتراضية 6.5%. زر حسبة جديدة يمسح المبلغ والمدة ويعيد النسبة إلى 6.5%. يمكن إدخال الأرقام العربية أو الإنجليزية. لا تُرسل بيانات التمويل إلى أي خادم. الخط Noto Kufi Arabic من Google Fonts، مع خط بديل عند عدم الاتصال.

## الاختبار

`node --test tests/calculator.test.cjs`

يشمل نسبة صفر، التسديد شهراً بشهر للتحقق من الرصيد المتناقص، مدة شهر واحد، مدد غير نمطية، نسباً صغيرة، ورفض المدخلات غير الصالحة.

## التشغيل والنشر

شغّل أي خادم ملفات ثابتة في جذر المشروع، مثلاً `python3 -m http.server 8080`.

للنشر المجاني: في GitHub افتح Settings → Pages واختر GitHub Actions كمصدر. سير العمل `.github/workflows/pages.yml` يختبر الحسابات ثم ينشر الملفات العامة فقط عند الدفع إلى `main`. إن تعذّر التفعيل التلقائي بسبب صلاحية رمز Actions، فعّل Pages من الإعدادات وأعد تشغيل سير العمل. لا توجد حزم للتثبيت أو خطوة بناء مطلوبة.

الرابط المتوقع بعد نجاح النشر: https://al9afey81.github.io/BANK-CALCULATOR/

الأيقونات PNG محلية، وملف manifest ومسارات جميع الموارد نسبية لتعمل تحت مسار المستودع. عامل الخدمة يتيح استخدام الملفات الأساسية دون اتصال بعد الزيارة الأولى، ويُفضّل الشبكة للحصول على التحديثات.
